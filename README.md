# City Police Crime Analysis & Interactive Excel Dashboard

## Project Overview

This project analyzes **5,250 city police crime incidents** using Microsoft Excel. The objective is to identify crime patterns, high-risk districts, crime severity, investigation workload, and financial impact to support **data-driven police resource allocation and decision-making**.

The project transforms raw crime incident data into a **cleaned dataset, Pivot Table analysis, and interactive Excel dashboard**.

## Business Objectives

* Identify the most frequently occurring crime types.
* Determine which districts have the highest crime rates.
* Analyze crime severity and its distribution.
* Monitor case status, including pending and under-investigation cases.
* Analyze property loss and financial impact.
* Provide actionable insights for police resource allocation.

## Key Dashboard Metrics

* Total Crime Incidents: **5,250**
* Most Frequent Crime: **Drunk Driving – 453 incidents**
* Highest Crime District: **Central District – 1,077 incidents**
* Critical-Severity Cases: **1,384**
* Cases Under Investigation: **1,120**
* Pending Cases: **737**
* Average Recorded Property Loss: **Approximately $24,982 per incident where loss data is available**

## Key Business Insights

### 1. Drunk Driving is the Most Frequent Crime

Drunk Driving accounts for **453 incidents**, making traffic enforcement and prevention a major police priority.

### 2. Central District is the Main Crime Hotspot

Central District records **1,077 incidents**, indicating a need for increased patrols and police presence.

### 3. Critical-Severity Crimes Require Priority Response

With **1,384 critical-severity incidents**, police management should prioritize rapid response and appropriate allocation of specialized resources.

### 4. Investigation Workload is Significant

There are **1,120 cases under investigation** and **737 pending cases**, highlighting the need to improve case resolution and reduce backlogs.

### 5. Crime Has a Significant Financial Impact

Property losses represent an important economic impact, supporting greater focus on crimes that create both high public-safety and financial risks.

## Police Attention Priorities

1. Strengthen traffic enforcement and prevention of Drunk Driving.
2. Allocate additional resources to Central District.
3. Prioritize Critical-severity incidents for rapid response.
4. Reduce pending and under-investigation case backlogs.
5. Target crimes with high financial and public-safety impact.

## Dashboard Features

The interactive dashboard allows users to analyze crime data by different dimensions such as:

* Crime Type
* District
* Crime Severity
* Case Status
* Property Loss
* Other available categorical fields

**Slicers and interactive charts** make it possible for police management to filter the analysis and identify specific crime patterns quickly.

## Project Outcome

This project demonstrates how **Excel can be used as a practical data analytics and business intelligence tool** to transform raw crime data into meaningful insights. The dashboard provides police management with a clear view of crime patterns and helps support **data-driven decisions regarding patrol deployment, investigation priorities, and crime prevention strategies**.
